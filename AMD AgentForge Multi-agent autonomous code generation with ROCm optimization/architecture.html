Why AMD? — Technical Justification for Judges
01
192 GB HBM3 Unified Memory
The MI300X fits a 70B model in FP16 without tensor parallelism. No sharding overhead, no inter-GPU communication latency. /dev/kfd is the proof — we detect it at boot and activate the full ROCm compute path. One device, full model.
02
PagedAttention + FlashAttn-2 HIP
vLLM's PagedAttention allocates KV-cache in non-contiguous 16-token HBM3 blocks — up to 24× throughput vs naïve caching. FlashAttention-2's HIP port runs ~1.3× faster than the CUDA build on MI300X due to 3× more shared memory per CU. The Live Kernel Log shows flash_attn_fwd_rocm calls live.
03
Open, Zero-Config Kernel Path
ROCm is open-source. Our inference router detects /dev/kfd + /dev/dri/renderD* at startup — no vendor driver install step, no proprietary API. The same InferenceClient degrades gracefully to AWQ → GGUF → HF API with zero code changes. Fully reproducible on any AMD Instinct or RDNA3 system.
